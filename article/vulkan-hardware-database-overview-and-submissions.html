Vulkan Hardware Database: Overview and Submissions

The Vulkan Hardware Database is an essential public repository that tracks hardware specifications, driver features, and extension support across devices running the Vulkan graphics and compute API. This article explains the purpose of the database, why it is critical for graphics programmers, and the step-by-step process developers follow to generate and submit GPU capability reports using standard diagnostic tools.

What Is the Vulkan Hardware Database?

The Vulkan Hardware Database is an open-source, community-driven resource that catalogs the capabilities of Vulkan-compatible devices worldwide. Maintained primarily to assist cross-platform development, the platform aggregates detailed hardware metrics, including supported API versions, hardware limits, available extensions, memory configurations, and format features across various operating systems such as Windows, Linux, Android, and macOS (via MoltenVK).

Because Vulkan is a low-level explicit API, applications require precise information about device capabilities to allocate resources and execute pipelines correctly. The database provides a searchable, centralized index where developers can verify whether specific features—such as ray tracing extensions, mesh shaders, or subgroup operations—are supported across different GPU architectures and driver versions before writing or deploying code.

Why Developers Use the Database

  • Hardware Compatibility Verification: Developers can quickly determine market adoption rates for specific features and extensions without needing to purchase and test every physical GPU.
  • Driver Tracking: The database logs differences across driver releases, helping developers detect regressions or confirm when a driver update enables new functionality.
  • Coverage Analysis: By querying minimum and maximum limits (e.g., maximum image dimensions or uniform buffer ranges), developers can establish baseline requirements for their engines.

How to Submit GPU Capability Reports

Submitting capability reports to the database is an automated process handled by the Vulkan Hardware Capability Viewer, an open-source client application available for desktop and mobile platforms.

Follow these steps to generate and submit a report:

1. Download the Vulkan Hardware Capability Viewer

Download the appropriate version of the tool for your operating system (available on Windows, Linux, Android, and macOS). The tool is available via package managers, pre-compiled binaries, or through the Google Play Store for Android devices.

2. Run the Diagnostic Tool

Launch the viewer on the target machine with the relevant GPU and display driver enabled. Upon launch, the tool initializes a standard Vulkan instance and queries the underlying physical device properties via native Vulkan calls, such as:

  • vkGetPhysicalDeviceProperties
  • vkGetPhysicalDeviceFeatures
  • vkGetPhysicalDeviceMemoryProperties
  • vkEnumerateDeviceExtensionProperties

3. Review the Gathered Information

The user interface displays an organized breakdown of your device's implementation details, including supported Vulkan versions, available layers, pipeline stages, memory types, and supported texture formats.

4. Upload the Report to the Database

Once the inspection is complete, click the Submit or Upload button within the interface. The application serializes the hardware metrics into a standardized JSON payload and transmits it directly to the database servers. Users can optionally provide details such as custom comments or system notes before submitting.

Command-line versions of the tool also support headless execution and automated uploads using flags (such as -u or --upload), allowing developers to integrate hardware reporting into continuous integration (CI) environments and automated test benches. Once submitted, the report is validated and immediately indexed for public search and comparison.
