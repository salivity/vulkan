Vulkan Pipeline Statistics Query Counters Guide

Vulkan provides developers with low-level access to GPU performance metrics through pipeline statistics queries. By creating query pools configured with the pipeline statistics query type, applications can measure how workloads move through both graphics and compute pipelines. This article details the specific counters recorded by Vulkan pipeline queries, covering metrics from vertex and compute shader invocations to primitive assembly and rasterization stages.

Overview of Vulkan Pipeline Statistics

Pipeline statistics in Vulkan are captured using query pools created with VK_QUERY_TYPE_PIPELINE_STATISTICS. When creating the pool via VkQueryPoolCreateInfo, the pipelineStatistics field specifies a bitmask of VkQueryPipelineStatisticFlagBits that dictates which hardware counters to record between vkCmdBeginQuery and vkCmdEndQuery calls.

Each enabled bit corresponds to a 64-bit unsigned integer counter written into the query results.

Input Assembly Counters

The input assembly stage reads raw vertex and index data from memory buffers to assemble basic primitives for subsequent pipeline stages.

  • Input Assembly Vertices (VK_QUERY_PIPELINE_STATISTIC_INPUT_ASSEMBLY_VERTICES_BIT): Counts the total number of vertices processed by the input assembly stage. In indexed drawing commands (vkCmdDrawIndexed), this counter increments for every index referenced, regardless of vertex cache hits.
  • Input Assembly Primitives (VK_QUERY_PIPELINE_STATISTIC_INPUT_ASSEMBLY_PRIMITIVES_BIT): Counts the total number of complete geometric primitives (points, lines, or triangles) assembled. Incomplete primitives, such as trailing vertices in incomplete triangle strips, are not counted.

Shader Invocation Counters

Vulkan allows tracking execution counts across individual programmable shader stages.

  • Vertex Shader Invocations (VK_QUERY_PIPELINE_STATISTIC_VERTEX_SHADER_INVOCATIONS_BIT): Records the number of times a vertex shader is executed. Implementations often optimize execution via post-transform vertex caches; this counter reflects the actual number of invocations executed by the hardware rather than total input vertices.
  • Geometry Shader Invocations (VK_QUERY_PIPELINE_STATISTIC_GEOMETRY_SHADER_INVOCATIONS_BIT): Measures how many times a geometry shader is invoked. For instanced geometry shaders, each instance counts as an independent invocation.
  • Geometry Shader Primitives (VK_QUERY_PIPELINE_STATISTIC_GEOMETRY_SHADER_PRIMITIVES_BIT): Records the total number of primitives emitted by all geometry shader invocations via output commands like EmitVertex() and EndPrimitive().
  • Fragment Shader Invocations (VK_QUERY_PIPELINE_STATISTIC_FRAGMENT_SHADER_INVOCATIONS_BIT): Tracks the number of times a fragment shader is invoked. This counter is heavily influenced by MSAA sample rates, helper invocations (quads used for calculating screen-space derivatives), and early-Z fragment rejection.
  • Compute Shader Invocations (VK_QUERY_PIPELINE_STATISTIC_COMPUTE_SHADER_INVOCATIONS_BIT): Counts the total number of compute shader work items (threads) executed across all workgroups dispatched via vkCmdDispatch or indirect dispatch commands.

Tessellation Stage Counters

When tessellation is active, specific counters monitor patch processing and evaluation steps.

  • Tessellation Control Shader Patches (VK_QUERY_PIPELINE_STATISTIC_TESSELLATION_CONTROL_SHADER_PATCHES_BIT): Counts the number of input patches processed by the tessellation control (hull) shader.
  • Tessellation Evaluation Shader Invocations (VK_QUERY_PIPELINE_STATISTIC_TESSELLATION_EVALUATION_SHADER_INVOCATIONS_BIT): Tracks the number of times the tessellation evaluation (domain) shader is executed to evaluate generated vertices from the tessellator.

Primitive Clipping Counters

The fixed-function clipping stage determines whether primitives fall within the view frustum or user-defined clip planes.

  • Clipping Invocations (VK_QUERY_PIPELINE_STATISTIC_CLIPPING_INVOCATIONS_BIT): Measures the number of primitives processed by the clipper.
  • Clipping Primitives (VK_QUERY_PIPELINE_STATISTIC_CLIPPING_PRIMITIVES_BIT): Measures the number of primitives that survived the clipping stage and were forwarded to rasterization. If a single polygon is subdivided into multiple smaller primitives during clipping, the counter reflects the increased count. Primitives entirely outside the view volume increment the invocation counter but not this counter.

Mesh Shading Extension Counters

When using the VK_EXT_mesh_shader extension, additional counters track the modern geometry pipeline:

  • Task Shader Invocations (VK_QUERY_PIPELINE_STATISTIC_TASK_SHADER_INVOCATIONS_BIT_EXT): Tracks the total number of individual work items executed within task shader workgroups.
  • Mesh Shader Invocations (VK_QUERY_PIPELINE_STATISTIC_MESH_SHADER_INVOCATIONS_BIT_EXT): Tracks the total number of individual work items executed within mesh shader workgroups.
