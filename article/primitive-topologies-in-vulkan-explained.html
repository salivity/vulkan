Primitive Topologies in Vulkan Explained

In Vulkan, primitive topology dictates how the Input Assembly (IA) stage reads a continuous stream of vertex and index data and assembles it into geometric shapes for rendering. Configured via the VkPipelineInputAssemblyStateCreateInfo structure using the VkPrimitiveTopology enum, topologies define the connectivity rules for vertices. This article breaks down how Vulkan processes points, lines, triangle variants, adjacency data, and tessellation patch lists, as well as the role of primitive restart.

Point Topologies

Point List (VK_PRIMITIVE_TOPOLOGY_POINT_LIST)

In a point list, every individual vertex in the buffer represents a discrete point. If you provide \(N\) vertices, the input assembler emits \(N\) points. Point size must be defined in the vertex shader using the gl_PointSize built-in variable unless the pipeline has wide lines or specific point-size dynamic states disabled.

Line Topologies

Line primitives connect pairs of vertices to form segments.

  • Line List (VK_PRIMITIVE_TOPOLOGY_LINE_LIST): Vertices are processed in non-overlapping pairs. Vertices \((0, 1)\) define the first line, \((2, 3)\) define the second, and so on. An odd number of vertices results in the final incomplete pair being discarded.
  • Line Strip (VK_PRIMITIVE_TOPOLOGY_LINE_STRIP): Vertices form a continuous connected path. The first line spans \((0, 1)\), the second spans \((1, 2)\), the third \((2, 3)\), and each subsequent vertex adds another segment connected to the previous one.

Triangle Topologies

Triangles are the standard primitive for 3D meshes and define solid geometric surfaces.

  • Triangle List (VK_PRIMITIVE_TOPOLOGY_TRIANGLE_LIST): Vertices are read in groups of three. Vertices \((0, 1, 2)\) form the first triangle, \((3, 4, 5)\) form the second, and so on. Incomplete groups of fewer than three vertices are dropped.
  • Triangle Strip (VK_PRIMITIVE_TOPOLOGY_TRIANGLE_STRIP): Vertices create an interconnected strip where each triangle shares two vertices with its predecessor. Triangle 0 is formed by \((0, 1, 2)\), triangle 1 by \((1, 2, 3)\), triangle 2 by \((2, 3, 4)\), etc. Vulkan automatically alternates the winding order internally for even-numbered triangles to ensure consistent front-face culling across the strip.
  • Triangle Fan (VK_PRIMITIVE_TOPOLOGY_TRIANGLE_FAN): All triangles share the initial root vertex (vertex 0). Triangle 0 is \((0, 1, 2)\), triangle 1 is \((0, 2, 3)\), and triangle \(i\) is \((0, i+1, i+2)\). This topology is rarely used in modern rendering pipelines due to memory bottlenecks at the shared vertex and poor post-transform cache behavior.

Adjacency Topologies

Adjacency topologies provide neighborhood information to the Geometry Shader stage to assist with algorithms like silhouette detection, shadow volume generation, and edge-preserving subdivision.

  • Line List with Adjacency (VK_PRIMITIVE_TOPOLOGY_LINE_LIST_WITH_ADJACENCY): Requires four vertices per primitive. Vertices 1 and 2 define the visible segment, while vertices 0 and 3 provide adjacent neighbor points.
  • Line Strip with Adjacency (VK_PRIMITIVE_TOPOLOGY_LINE_STRIP_WITH_ADJACENCY): Consists of a connected path where internal segments share endpoints and neighbor data.
  • Triangle List with Adjacency (VK_PRIMITIVE_TOPOLOGY_TRIANGLE_LIST_WITH_ADJACENCY): Requires six vertices per triangle. Vertices 0, 2, and 4 form the primary rendered triangle, while vertices 1, 3, and 5 represent the adjacent neighbor vertices sharing those edges.
  • Triangle Strip with Adjacency (VK_PRIMITIVE_TOPOLOGY_TRIANGLE_STRIP_WITH_ADJACENCY): A continuous strip where neighbor vertices are interleaved with primary vertices according to a structured winding layout.

These adjacency primitives cannot be rendered directly by rasterization stages and require a Geometry Shader or Mesh Shader to unpack them into standard renderable primitives.

Patch Lists (VK_PRIMITIVE_TOPOLOGY_PATCH_LIST)

Patch lists are used strictly when tessellation is enabled (requiring Tessellation Control and Tessellation Evaluation shaders).

Unlike triangle or line topologies, a patch list does not imply any fixed geometric structure at the input assembler stage. Instead, a patch is an arbitrary collection of control points. The number of vertices per patch is configured using the patchControlPointCount member of VkPipelineTessellationStateCreateInfo, ranging from 1 to 32 (subject to device limits defined by maxTessellationPatchSize).

The Tessellation Control Shader receives the patch, defines tessellation factors, and the hardware tessellator generates standard triangles or quads according to your shader's algorithmic rules.

Primitive Restart

When using indexed drawing commands (vkCmdDrawIndexed or vkCmdDrawIndexedIndirect) with strip-based topologies (such as LINE_STRIP or TRIANGLE_STRIP), you can break a strip and start a new one without issuing a separate draw call.

By enabling primitiveRestartEnable in VkPipelineInputAssemblyStateCreateInfo, Vulkan reserves the maximum integer value of the index buffer format (0xFFFF for VK_INDEX_TYPE_UINT16 or 0xFFFFFFFF for VK_INDEX_TYPE_UINT32). Whenever the Input Assembler encounters this sentinel index value, it terminates the active strip and begins assembling the next primitive from the following index.
