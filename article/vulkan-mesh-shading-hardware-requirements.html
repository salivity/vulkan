Vulkan Mesh Shading Hardware Requirements

Mesh shading in the Vulkan graphics API replaces the traditional fixed-function geometry processing pipeline—composed of vertex, tessellation, and geometry shaders—with a flexible, compute-centric workflow driven by task and mesh shader stages. To implement this pipeline using the cross-vendor VK_EXT_mesh_shader extension, systems require modern GPU architectures featuring specialized hardware support for direct primitive generation alongside compatible display drivers.

Supported GPU Architectures

To run Vulkan mesh shading pipelines, the underlying graphics processor must natively support cooperative thread-group-based primitive output. The minimum required hardware architectures include:

  • NVIDIA: Turing architecture (GeForce RTX 20-series, GTX 16-series) or newer. This includes Ampere (RTX 30-series), Ada Lovelace (RTX 40-series), and corresponding workstation Quadro/RTX cards. Earlier architectures (Pascal and older) lack the internal hardware scheduling required for mesh shading.
  • AMD: RDNA 2 architecture (Radeon RX 6000-series) or newer, such as RDNA 3 (RX 7000-series). Older GCN and first-generation RDNA architectures do not feature the primitive shader execution models needed to fulfill the Vulkan mesh shading specification.
  • Intel: Intel Arc Alchemist (Xe-HPG) discrete GPUs or integrated Xe-LPG architectures (found in Intel Core Ultra processors) and newer. Legacy Intel UHD and Iris Xe (Xe-LP) graphics are unsupported.
  • Mobile Platforms: Premium mobile chipsets featuring GPUs such as Qualcomm Adreno 700-series (Snapdragon 8 Gen 1 and newer) and Arm Immortalis-G715/G720 or newer, provided that the OEM provides appropriate driver-level exposed extensions.

Core Pipeline Capabilities and Extensions

In addition to base GPU architecture support, hardware must expose specific Vulkan features and extensions to function properly:

  • VK_EXT_mesh_shader: The definitive multi-vendor standard supported across AMD, Intel, and NVIDIA. Older NVIDIA-specific implementations relied on VK_NV_mesh_shader, which is strictly limited to NVIDIA hardware and has largely been superseded by the EXT standard.
  • Subgroup and Compute Capabilities: Hardware must support subgroup operations (typically subgroup sizes of 32 or 64 threads) and provide adequate on-chip shared local memory (Workgroup Local Memory) to manage the assembly of vertices and primitives within a meshlet.
  • Driver Requirements: An installed graphics driver exposing Vulkan 1.2 or Vulkan 1.3 conformance with explicit reporting of mesh shader properties (such as maximum output vertices and primitives per mesh workgroup). Platforms running non-conformant or legacy drivers will fail to initialize the pipeline even on capable silicon.
