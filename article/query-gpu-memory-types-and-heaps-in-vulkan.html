Query GPU Memory Types and Heaps in Vulkan

In the Vulkan graphics and compute API, managing GPU memory requires developers to explicitly allocate and bind memory to buffers and images. To accomplish this, developers must first inspect the hardware's memory architecture by querying the available memory heaps and memory types. This guide explains how to use Vulkan's physical device interface to retrieve memory properties, examine memory heaps and memory types, and select the correct memory type index for resource allocation.

Understanding Heaps and Memory Types

Vulkan exposes device memory through two core abstractions contained within the VkPhysicalDeviceMemoryProperties structure:

  • Memory Heaps (VkMemoryHeap): Represent physical memory reserves, such as dedicated video RAM (VRAM) on a discrete graphics card or shared system RAM in an integrated setup. Each heap reports its total size in bytes and state flags, such as VK_MEMORY_HEAP_DEVICE_LOCAL_BIT.
  • Memory Types (VkMemoryType): Represent specific ways to access and cache memory from a given heap. Each memory type points to a parent heap via heapIndex and specifies property flags defining its behavior, such as VK_MEMORY_PROPERTY_HOST_VISIBLE_BIT (mappable by the CPU) or VK_MEMORY_PROPERTY_HOST_COHERENT_BIT (no manual cache flushing required).

Retrieving Physical Device Memory Properties

To retrieve this information, you call vkGetPhysicalDeviceMemoryProperties, passing a valid VkPhysicalDevice handle and a pointer to an uninitialized VkPhysicalDeviceMemoryProperties structure.

VkPhysicalDeviceMemoryProperties memProperties;
vkGetPhysicalDeviceMemoryProperties(physicalDevice, &memProperties);

Once executed, memProperties is populated with the counts and arrays of both heaps and types:

  • memProperties.memoryHeapCount: The number of valid memory heaps (up to VK_MAX_MEMORY_HEAPS).
  • memProperties.memoryHeaps: An array of VkMemoryHeap structures.
  • memProperties.memoryTypeCount: The number of valid memory types (up to VK_MAX_MEMORY_TYPES).
  • memProperties.memoryTypes: An array of VkMemoryType structures.

Inspecting Heaps and Types

Developers can iterate through the populated structure to evaluate hardware capabilities and memory budgets:

#include <vulkan/vulkan.h>
#include <iostream>

void PrintMemoryProperties(VkPhysicalDevice physicalDevice) {
    VkPhysicalDeviceMemoryProperties memProperties;
    vkGetPhysicalDeviceMemoryProperties(physicalDevice, &memProperties);

    std::cout << "Memory Heaps (" << memProperties.memoryHeapCount << "):\n";
    for (uint32_t i = 0; i < memProperties.memoryHeapCount; ++i) {
        VkDeviceSize sizeInMB = memProperties.memoryHeaps[i].size / (1024 * 1024);
        std::cout << "  Heap " << i << ": Size = " << sizeInMB << " MB";
        if (memProperties.memoryHeaps[i].flags & VK_MEMORY_HEAP_DEVICE_LOCAL_BIT) {
            std::cout << " [DEVICE LOCAL]";
        }
        std::cout << "\n";
    }

    std::cout << "\nMemory Types (" << memProperties.memoryTypeCount << "):\n";
    for (uint32_t i = 0; i < memProperties.memoryTypeCount; ++i) {
        std::cout << "  Type " << i << ": Heap " << memProperties.memoryTypes[i].heapIndex << " | Flags: ";
        VkMemoryPropertyFlags flags = memProperties.memoryTypes[i].propertyFlags;
        
        if (flags & VK_MEMORY_PROPERTY_DEVICE_LOCAL_BIT) std::cout << "DEVICE_LOCAL ";
        if (flags & VK_MEMORY_PROPERTY_HOST_VISIBLE_BIT) std::cout << "HOST_VISIBLE ";
        if (flags & VK_MEMORY_PROPERTY_HOST_COHERENT_BIT) std::cout << "HOST_COHERENT ";
        if (flags & VK_MEMORY_PROPERTY_HOST_CACHED_BIT)   std::cout << "HOST_CACHED ";
        std::cout << "\n";
    }
}

Selecting a Memory Type for Allocations

When creating a resource (such as a VkBuffer or VkImage), you must query its specific requirements using vkGetBufferMemoryRequirements or vkGetImageMemoryRequirements. The returned VkMemoryRequirements structure contains a bitmask called memoryTypeBits.

To allocate memory via vkAllocateMemory, find an index i that satisfies both the resource's requirements and your application's access requirements:

uint32_t FindMemoryType(VkPhysicalDevice physicalDevice, uint32_t typeFilter, VkMemoryPropertyFlags properties) {
    VkPhysicalDeviceMemoryProperties memProperties;
    vkGetPhysicalDeviceMemoryProperties(physicalDevice, &memProperties);

    for (uint32_t i = 0; i < memProperties.memoryTypeCount; ++i) {
        // Check if the resource supports this memory type
        bool typeSupported = (typeFilter & (1 << i)) != 0;
        // Check if the memory type contains the required property flags
        bool propertiesMet = (memProperties.memoryTypes[i].propertyFlags & properties) == properties;

        if (typeSupported && propertiesMet) {
            return i;
        }
    }

    // Handle failure (e.g., throw an exception or return an error code)
    return UINT32_MAX;
}

The returned index is assigned to the memoryTypeIndex field of VkMemoryAllocateInfo before invoking vkAllocateMemory.
