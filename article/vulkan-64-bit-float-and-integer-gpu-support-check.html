Vulkan 64-Bit Float and Integer GPU Support Check

To determine whether a GPU supports 64-bit integer or 64-bit floating-point math in the Vulkan API, an application must query the physical device's feature set. Vulkan exposes these capabilities through specific boolean flags—shaderInt64 and shaderFloat64—located within the standard device features structure. By inspecting these flags before logical device creation, developers can verify hardware compatibility and enable the required arithmetic operations within their shader pipelines.

Querying Device Features

Before creating a logical device (VkDevice), the application enumerates physical devices (VkPhysicalDevice) and retrieves their supported capabilities using vkGetPhysicalDeviceFeatures or the extended vkGetPhysicalDeviceFeatures2.

VkPhysicalDeviceFeatures supportedFeatures;
vkGetPhysicalDeviceFeatures(physicalDevice, &supportedFeatures);

VkBool32 has64BitFloat = supportedFeatures.shaderFloat64;
VkBool32 has64BitInt   = supportedFeatures.shaderInt64;
  • 64-Bit Floating-Point (shaderFloat64): Indicates whether 64-bit floats (double in GLSL) can be used in shader code. If set to VK_TRUE, the GPU supports 64-bit float types, storage, and standard arithmetic operations.
  • 64-Bit Integer (shaderInt64): Indicates whether signed and unsigned 64-bit integers (int64_t, uint64_t in GLSL) are supported in shaders. If set to VK_TRUE, 64-bit integer types and operations are accessible.

Enabling Features at Device Creation

Detecting support is only the first step. If the target GPU supports these features, the application must explicitly request and enable them when calling vkCreateDevice. If a feature is not explicitly enabled during device creation, using it in shaders will result in validation errors or pipeline compilation failures.

VkPhysicalDeviceFeatures enabledFeatures = {};

if (supportedFeatures.shaderFloat64) {
    enabledFeatures.shaderFloat64 = VK_TRUE;
}

if (supportedFeatures.shaderInt64) {
    enabledFeatures.shaderInt64 = VK_TRUE;
}

VkDeviceCreateInfo createInfo = {};
createInfo.sType = VK_STRUCTURE_TYPE_DEVICE_CREATE_INFO;
createInfo.pEnabledFeatures = &enabledFeatures;
// Fill out queue create infos, extensions, etc.

VkDevice device;
vkCreateDevice(physicalDevice, &createInfo, NULL, &device);

For applications utilizing Vulkan 1.1 or later, the query can also be performed via VkPhysicalDeviceFeatures2 with vkGetPhysicalDeviceFeatures2. This structure can be chained with other feature extensions (such as VkPhysicalDeviceVulkan12Features or VkPhysicalDeviceShaderFloat16Int8Features) if advanced arithmetic control—like storage-only support—is required.

Shader Implementation Requirements

Once detected and enabled at the API level, the corresponding features must be declared within the shader source code (such as GLSL):

  • For 64-bit floating-point:

    #version 450
#extension GL_ARB_gpu_shader_fp64 : enable

  • For 64-bit integers:

    #version 450
#extension GL_ARB_gpu_shader_int64 : enable

If the underlying hardware returns VK_FALSE for either capability, the application must implement a fallback algorithm using 32-bit types or select a different physical device capable of handling 64-bit precision.
