AMD Tools for Vulkan Shader Profiling

Optimizing shader execution in Vulkan requires deep hardware-level visibility to eliminate stalls, balance register usage, and maximize compute unit occupancy. AMD provides a specialized suite of performance profiling and static analysis tools—most notably the Radeon GPU Profiler (RGP) and Radeon GPU Analyzer (RGA)—that allow developers to inspect Vulkan graphics, compute, and ray tracing shaders down to the hardware instruction level on RDNA and GCN architectures.

Radeon GPU Profiler (RGP)

The Radeon GPU Profiler (RGP) is AMD's flagship tool for dynamic, runtime performance profiling. It integrates directly with Vulkan applications to capture detailed frame data and expose how shaders execute across the GPU's Compute Units (CUs) or Workgroup Processors (WGPs).

  • Instruction-Level Profiling: RGP correlates SPIR-V shaders with generated AMD machine code (ISA). It displays program counter sampling, allowing developers to see precisely which instructions—such as memory loads, branch divergence, or transcendentals—cause latency or stalls.
  • Wavefront Occupancy and State: The tool visualizes wave occupancy over time, detailing whether waves are actively executing ALU operations, waiting on scalar/vector memory (SALU/VALU), or stalled due to export dependencies and pipeline barriers.
  • Register Pressure Tracking: RGP visualizes Vector General Purpose Register (VGPR) and Scalar General Purpose Register (SGPR) usage per shader stage. High register allocation limits the number of simultaneously resident waves; RGP shows how register footprints impact theoretical versus achieved occupancy.
  • Cache and Memory Metrics: Developers can inspect hit/miss rates across the L0, L1, L2, and Infinity Cache hierarchies for shader storage buffers (SSBOs), uniform buffers (UBOs), and sampled textures.

Radeon GPU Analyzer (RGA)

The Radeon GPU Analyzer (RGA) is a static analysis compiler and code-generation tool designed for offline shader tuning. It allows developers to compile Vulkan GLSL source code or pre-compiled SPIR-V binaries directly target-specific AMD GPU architectures without needing the target hardware installed on the host machine.

  • Targeted ISA Disassembly: RGA compiles SPIR-V code for arbitrary RDNA and GCN generations, outputting human-readable assembly instructions alongside the intermediate language.
  • Static Resource Footprint: Upon compilation, RGA outputs comprehensive statistics, including exact VGPR and SGPR counts, scratch memory spilling, code size, and theoretical maximum wave occupancy per SIMD.
  • Live Register Analysis: When using the GUI version of RGA, lines of source code or SPIR-V are mapped directly to live ranges of registers, highlighting precisely where variables extend register lifetime and push the shader into lower occupancy thresholds.

Radeon Developer Panel (RDP)

The Radeon Developer Panel serves as the runtime host and communication interface between the developer workstation and the target Vulkan application.

  • Injects the profiling hooks into the Vulkan loader without requiring source-code modifications.
  • Facilitates the trigger of RGP profiling bursts precisely when specific frame conditions, execution times, or pipeline configurations occur.

Radeon Raytracing Analyzer (RRA)

For applications utilizing the VK_KHR_ray_tracing extensions, the Radeon Raytracing Analyzer provides deep inspection of ray generation, closest hit, any hit, and intersection shaders.

  • Traversal Cost Visualization: RRA overlays heatmaps showing traversal iterations and intersection testing overhead directly onto scene geometry.
  • BVH Inspection: Analyzes the efficiency of Bottom-Level Acceleration Structures (BLAS) and Top-Level Acceleration Structures (TLAS) to identify poorly fitted bounding boxes that cause excessive shader execution time during traversal.
