Vulkan Depth Bounds Testing and Dynamic State Guide

The depth bounds test is an optimization feature in modern graphics pipelines that discards fragments based on the current depth value stored in the depth buffer relative to a defined range. In Vulkan, developers can configure this test dynamically to avoid rebuilding pipeline state objects when bounds change between rendering passes. This guide covers how the depth bounds test functions, its practical use cases, and the specific steps required to enable and configure it dynamically within a Vulkan application.

Function of the Depth Bounds Test

The depth bounds test evaluates whether the depth value already residing in the depth attachment at a fragment's coordinates falls between a specified minimum and maximum threshold (\([\text{minDepthBounds}, \text{maxDepthBounds}]\)). If the value in the depth buffer is outside this range, the incoming fragment is discarded prior to or after shading, preventing unnecessary color, stencil, or depth writes.

Unlike standard depth testing—which compares the incoming fragment's depth against the depth buffer—the depth bounds test evaluates the existing content of the depth buffer. This makes it particularly valuable for:

  • Deferred Shading: Restricting light volume rendering to the exact depth slices occupied by geometry, reducing overhead from overlapping light volumes.
  • Volume Rendering and Particle Systems: Confining effects to a specific depth region without reading the depth buffer directly in the fragment shader.
  • Post-processing Optimizations: Eliminating computation over areas of the screen containing clear values or background elements like skyboxes.

How to Enable Depth Bounds Dynamically in Vulkan

Using the depth bounds test dynamically allows you to modify the boundary values using command buffers instead of baking static values into a VkPipeline.

1. Check and Enable Physical Device Features

Depth bounds testing is an optional feature in Vulkan. You must query and enable it when creating your VkDevice.

VkPhysicalDeviceFeatures supportedFeatures;
vkGetPhysicalDeviceFeatures(physicalDevice, &supportedFeatures);

if (!supportedFeatures.depthBounds) {
    // Handle lack of support
}

VkPhysicalDeviceFeatures enabledFeatures{};
enabledFeatures.depthBounds = VK_TRUE;

VkDeviceCreateInfo createInfo{};
createInfo.sType = VK_STRUCTURE_TYPE_DEVICE_CREATE_INFO;
createInfo.pEnabledFeatures = &enabledFeatures;
// Populate remaining device creation structures and create device

2. Configure the Pipeline Depth/Stencil State

When creating your graphics pipeline (VkGraphicsPipelineCreateInfo), configure the VkPipelineDepthStencilStateCreateInfo struct to activate the test:

VkPipelineDepthStencilStateCreateInfo depthStencil{};
depthStencil.sType = VK_STRUCTURE_TYPE_PIPELINE_DEPTH_STENCIL_STATE_CREATE_INFO;
depthStencil.depthTestEnable = VK_TRUE; // or VK_FALSE depending on usage
depthStencil.depthWriteEnable = VK_TRUE;
depthStencil.depthBoundsTestEnable = VK_TRUE; // Enable the test
depthStencil.minDepthBounds = 0.0f; // Default baseline
depthStencil.maxDepthBounds = 1.0f; // Default baseline

3. Register the Dynamic State

To update bounds at runtime, add VK_DYNAMIC_STATE_DEPTH_BOUNDS to your pipeline’s dynamic state array:

VkDynamicState dynamicStates[] = {
    VK_DYNAMIC_STATE_VIEWPORT,
    VK_DYNAMIC_STATE_SCISSOR,
    VK_DYNAMIC_STATE_DEPTH_BOUNDS
};

VkPipelineDynamicStateCreateInfo dynamicStateInfo{};
dynamicStateInfo.sType = VK_STRUCTURE_TYPE_PIPELINE_DYNAMIC_STATE_CREATE_INFO;
dynamicStateInfo.dynamicStateCount = 3;
dynamicStateInfo.pDynamicStates = dynamicStates;

Attach this dynamicStateInfo struct to your VkGraphicsPipelineCreateInfo.

4. Set Bounds at Runtime

During command buffer recording, set the depth bounds dynamically before issuing draw calls using vkCmdSetDepthBounds:

// Example: Restrict rendering to geometry between depth 0.2 and 0.8
float minBounds = 0.2f;
float maxBounds = 0.8f;

vkCmdBindPipeline(commandBuffer, VK_PIPELINE_BIND_POINT_GRAPHICS, graphicsPipeline);
vkCmdSetDepthBounds(commandBuffer, minBounds, maxBounds);
vkCmdDraw(commandBuffer, vertexCount, instanceCount, 0, 0);

Both minDepthBounds and maxDepthBounds must reside between 0.0f and 1.0f inclusive, with minDepthBounds being less than or equal to maxDepthBounds. Modifying these values dynamically avoids pipeline switches and minimizes API overhead during rendering passes.
