Supported Codecs in Vulkan Video API

Vulkan Video introduces vendor-neutral, hardware-accelerated video decoding and encoding seamlessly integrated into the Vulkan graphics and compute API ecosystem. This article details the specific video compression codecs currently supported across the official Khronos Vulkan Video specifications, covering finalized production standards and emerging formats across decode and encode pipelines.

Finalized Video Decode Codecs

Vulkan Video provides fully ratified, cross-vendor extensions for hardware-accelerated video decoding. These operate alongside the base VK_KHR_video_queue and VK_KHR_video_decode_queue extensions:

  • H.264 / AVC (VK_KHR_video_decode_h264): Supports decoding of Advanced Video Coding streams up to High Profile. It handles intra-coded, predictive, and bidirectionally predictive frames with complete control over reference picture management.
  • H.265 / HEVC (VK_KHR_video_decode_h265): Supports High Efficiency Video Coding bitstreams, including Main and Main 10 profiles, allowing 8-bit and 10-bit color depths.
  • AV1 (VK_KHR_video_decode_av1): Ratified to support the modern, royalty-free AOMedia Video 1 format. It enables hardware decoding for the AV1 Main profile up to level 6.x, supporting 8-bit and 10-bit 4:2:0 content.

Finalized Video Encode Codecs

Hardware video encoding profiles require integration with VK_KHR_video_encode_queue to control quantization parameters, rate control algorithms, and picture generation:

  • H.264 / AVC (VK_KHR_video_encode_h264): Provides standardized hardware compression targeting baseline, main, and high profiles. It supports CBR (Constant Bitrate), VBR (Variable Bitrate), and direct frame-level control over intra and inter prediction.
  • H.265 / HEVC (VK_KHR_video_encode_h265): Standardizes hardware HEVC encoding for modern streaming and recording workflows, providing full support for Main and Main 10 profiles.

Provisional and Roadmap Codecs

  • AV1 Encode (VK_KHR_video_encode_av1): Khronos maintains active development for AV1 hardware encoding extensions, designed to enable royalty-free AV1 compression directly inside the Vulkan timeline without proprietary platform layers.

Technical Implementation

All supported codecs operate via standardized Vulkan command buffers. Decoded video frames reside directly in VkImage memory, eliminating host-to-device memory copies when feeding decoded frames into graphics rendering pipelines, compute shaders, or machine learning workloads. Hardware support is provided across modern graphics hardware from AMD, Intel, and NVIDIA via standard driver updates.
